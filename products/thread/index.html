AX Memory

The governed knowledge layer.

AX Memory is the product model for persistent team context: what the team currently knows, where it came from, what changed, and what remains uncertain. The records in this MVP are synthetic and local to one browser; team-wide shared memory would require a backend.

M

Source-linked facts

Each current value points back to its source and keeps the earlier value when a person reviews a change.

  • Provenance and confirmation details
  • Conflicts shown side by side
  • Unverified items stay visible until resolved
H

Decision history

Decisions are appended with the person, time, and optional rationale. A later decision can supersede an earlier entry without erasing it.

  • Readable source and review history
  • Open tasks tied to a context record
  • Browser-local persistence in this MVP
AX Workspace

The surface where people review, decide, and act.

AX Workspace turns context into a concrete human workflow. Thread does not make consequential decisions or contact anyone on a person’s behalf.

W

Four working views

Today prioritizes decisions and due work. My Work filters tasks by a demo team member. Context holds the records. History shows readable changes.

Human control and MVP limits

Clear boundaries between the product idea and this demo.

This page describes the intended AX Memory and AX Workspace model. The current static build demonstrates local state changes only.

People decide

Thread surfaces evidence and options. The person decides whether to accept, correct, reject, defer, or record a decision.

No AI is running

The sample proposals are pre-written for this demo. Manually added sources do not trigger automated extraction.

No external actions

The demo does not send messages, contact suppliers, update files, sync a team workspace, or deliver notifications.

Working MVP with synthetic data. State is saved in this browser only. There is no backend, multi-user state, real-time sync, authentication or permissions, server-side audit, live source connector, notification delivery, or running AI in this demo.
