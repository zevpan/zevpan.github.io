Thread

A Team Workspace for relationship-driven work. Thread keeps shared context current, notices what changed, and helps teams focus on the work that deserves human attention.

SELF-INITIATED PRODUCT BUILD

Memory → Intelligence → Workspace → Human Action

Thread is not positioned as a CRM replacement or autonomous outreach bot. Existing CRM, email, messaging, meetings and spreadsheets can remain source systems. Thread acts as a shared context and decision workspace above them.

Relationship Memory

Persistent context across people, companies, conversations, commitments, previous actions, overrides and provenance.

Signals

Detect meaningful changes such as replies, reconnect dates, new opportunity signals and ambiguous identity.

Decision Intelligence

Combine deterministic rules, capacity constraints and AI interpretation to decide what deserves attention.

Team Workspace

Give humans one shared surface for priority work, evidence, timelines, reconciliation, audit and action.

The MVP is functional, not just a mockup.

The public demo uses synthetic data, but the state transitions are real within the application. A new event can change relationship state, invalidate an older recommendation, update the workspace and record the decision trail.

Source Events → Relationship Memory → Rules + AI Assistance → Team Workspace → Human Action ↺
Cost discipline

MVP 0 runs with no paid infrastructure. The next version is designed around Next.js + Supabase free tier, with AI calls added only where unstructured interpretation materially improves the workflow.
